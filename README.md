# Расписание

Личное приложение со школьным расписанием: текущий урок с прогрессом, расписание по дням, секции (домашка, кружки, контрольные, заметки) и редактирование прямо в интерфейсе.

**Стек:** React 19 + TypeScript + Vite, zustand (состояние), dnd-kit (перетаскивание), read-excel-file (импорт .xlsx), lucide (иконки). Без бэкенда: данные хранятся в `localStorage` и не пропадают после перезагрузки.

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # production-сборка в dist/ (статические файлы, можно выложить куда угодно)
```

Для проверки вёрстки в любой момент дня: `?now=2026-09-22T10:30` в адресе.

## Как загрузить расписание

1. Google Таблицы → Файл → Скачать → Microsoft Excel (.xlsx).
2. В приложении: Настройки → Импорт расписания (или кнопка на пустой главной).
3. Проверить предпросмотр → «Импортировать».

Импорт понимает частые форматы: строки по дням (`День / № / Время / Предмет / Кабинет / Учитель`, в т. ч. объединённые ячейки дня), сетку «дни — колонки», отдельную таблицу звонков, время как текст `8.30-9.15` или как время Excel.

Исходное расписание (из `raspisanie_urokov_starshego.xlsx`) лежит в `src/data/initial-schedule.json` и загружается при первом открытии, а также после «Сбросить к исходному» в Настройках. Чтобы обновить его для всех устройств — поправьте этот файл.

## Архитектура

```
src/
  domain/        модель и чистая логика: типы, время/фазы дня, цвета предметов, реестр типов секций
  data/          слой хранения: ScheduleRepository (localStorage), валидация, начальные данные
  store/         zustand-store с действиями (добавить/изменить/удалить/переставить) + автосохранение
  import/        разбор .xlsx / .csv / .json → уроки
  ui/            компоненты: карточки, bottom sheet / диалоги, формы, навигация
  pages/         Сегодня · Расписание · Секции · Настройки
  styles/        дизайн-токены, база, компоненты
```

- **Бэкенд позже:** реализовать `ScheduleRepository` (например, HTTP) в `src/data/repository.ts` — UI и store менять не нужно.
- **Новый тип секции:** добавить запись в `SECTION_KINDS` (`src/domain/sectionKinds.ts`) — формы и карточки строятся по описанию полей.
